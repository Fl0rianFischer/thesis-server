# CV

Everything the agent knows about you. It scores projects against this file and
writes letters from it, and **it is instructed never to claim anything this
file does not support** — so a gap here becomes a project you never hear about,
and a vague line here becomes a vague letter.

Replace every placeholder below. The headings are the structure the prompt
expects; the content under them is yours.

> Written for the agent, not for a client. Nobody sees this file but you and it.
> Blunt notes beat polished prose: "Kubernetes — can operate, would not design a
> cluster from scratch" is worth more than a bullet reading "Kubernetes".

prevents the most damaging failure mode, so fill it in even though it feels

## Not interested

- <e.g. Anything where the description is entirely buzzwords with no system

## Things worth mentioning when they fit

Specifics an agent would not infer from a skills list, and that make a letter
concrete: a migration you led, a system you scaled, an open-source project, a
talk you gave, a certification a client asked for.

- <e.g. "Migrated a 400-table Postgres monolith to event sourcing over 18
  months, no downtime — good to cite for legacy-modernisation projects.">
